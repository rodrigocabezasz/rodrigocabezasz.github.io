## Carrusel de Inspiración Diaria

**Full-Stack · FastAPI + Streamlit + MySQL**

Aplicación web que muestra frases motivacionales con imágenes de fondo dinámicas desde la API de Unsplash. Backend en FastAPI sirviendo datos desde MySQL; frontend en Streamlit con auto-refresh.

**[Demo en Vivo](https://inspiracion-diaria.streamlit.app/)** · **[Código en GitHub](https://github.com/rodrigocabezasz/inspiracion-diaria-fastapi-streamlit)**

## Agregador de Noticias RSS

**Microservicio · FastAPI + Streamlit**

Sistema compuesto por una API (FastAPI) que extrae y normaliza noticias de múltiples fuentes RSS, y una aplicación (Streamlit) que las consume y presenta con filtros por fuente y categoría.

**[Código en GitHub](https://github.com/rodrigocabezasz/agregador-noticias-fastapi-streamlit)**

## Scraper Multi-Fuente de Imágenes

**ETL · Python + MySQL**

Script ETL que obtiene datos e imágenes de 4 APIs distintas (Unsplash, Pexels, Pixabay, NASA APOD), los normaliza y almacena en MySQL. Incluye manejo robusto de errores, rate limiting y gestión segura de credenciales.

**[Código en GitHub](https://github.com/rodrigocabezasz/scraper-multifuente-imagenes)**

## Framework de Gestión (Serie de Blog)

**Backend · FastAPI + Streamlit + Docker + MySQL**

Framework modular y reutilizable para sistemas de Control de Gestión empresarial. Documenta el proceso completo de construcción: arquitectura de microservicios, autenticación JWT, endpoints CRUD, integración de frontend y gestión de datos maestros.

Documentado en una [serie de 5 posts en el blog](../blog/2024/08/framework-gestion-parte-1-arquitectura/) con código incluido.
